AD-07-1 The blog Site - Group
Trabajo colaborativo
Taqueria los amos del camino - Blog

Objetivo

Desarrollar un sitio web utilizando HTML y CSS para practicar la estructura de páginas web, la navegación entre secciones y el diseño de una interfaz visualmente atractiva.

Descripción del proyecto

Es un sitio web que busca compartir información de una taqueria y ofrecer a los usuarios una experiencia sencilla para conocer el contenido del blog, los paquetes que se ofrecen y los medios de contacto.


Tecnologías utilizadas

HTML: estructura y organización del contenido.
CSS: styles, colors, layout and layout of pages.

🎨 Color Palette — Fireside
La paleta Fireside combina tonos cálidos de naranja, rojo, beige y café, inspirados en la calidez del fuego.
Color	HEX	Uso sugerido
Naranja	#E76814	Botones principales y elementos destacados
Beige	#D8D4BC	Fondos claros y secciones neutras
Rojo oscuro	#891A10	Títulos, énfasis y detalles oscuros
Naranja tostado	#DC8236	Botones secundarios y elementos decorativos
Rojo	#B8210F	Acciones importantes y destacados visuales
Café	#714236	Pie de página, detalles de texto y secciones oscuras
Principio de diseño: Equilibrar los colores vibrantes con fondos neutros para lograr una interfaz cálida, legible y visualmente atractiva.


Git y GitHub: control de versiones y colaboración en equipo, si se utilizaron.

Funcionalidades

Navegación entre las páginas del sitio.
Presentación de información sobre tacos.
Sección de contacto con datos informativos.
Visualización de imagenes para conocer el lugar.
